# Ресерч: цифровые двойники металлургических цехов в России

Дата: ноябрь 2026. Сводка по открытым источникам (пресс-релизы, СМИ). Первоисточники открыты не все — перед использованием цифр в презентации заводу перепроверяй.

## Главный вывод
- Готовых публичных 3D/BIM-моделей, планировок и паспортов оборудования цехов НЛМК, ММК, ТМК, Северстали, ЕВРАЗа **нет** (коммерческая тайна, безопасность объектов).
- Заводы делают в основном **двойники процессов** (нагрев, охлаждение, потоки) внутри MES, без пространственной 3D-модели цеха. Пространственный двойник цеха с живой симуляцией и прогулкой — свободная ниша.
- По открытым данным реально сделать **правдоподобный макет в реальных габаритах**; точность «один в один» — только по документам завода под NDA.

## Кандидаты на первый металлургический двойник
1. **ЧТПЗ, цех «Высота 239» (ТМК) — выбран первым.** Длина ≈720 м, ширина ≈150 м, запуск 2010; одношовные трубы 508–1420 мм с наружным и внутренним покрытием; оборудование SMS Meer (бюджет ≈900 млн $). Участки по потоку: склад листа → шаговая формовка (JCOE) → сварка → отделка → внутреннее и наружное антикоррозионное покрытие → отгрузка. Есть фото- и видеоэкскурсии. Логическая связь с двойником ЭПК (порошковые краски для изоляции труб).
   Нет в открытых данных: пролёты, краны, точная расстановка, параметры прессов JCOE.
2. **ПНТЗ, Финишный центр (цех №4)** — НКТ и обсадные трубы 60–178 мм, премиальные резьбы, муфты. Размеров цеха в открытых источниках нет.
3. **ПНТЗ, «Железный Озон 32»** — ЭСПК, дуговая печь 125 т, ≈900 тыс. т/год, площадь цеха ≈50 000 м² (комплекс 80 000 м²), заготовка 150–550 мм.
4. **ММК, стан 2500 ЛПЦ №4** — у завода уже есть двойники процессов, можно «одеть» в 3D; геометрии в открытых данных почти нет.

## Где брать данные
Без завода:
- спутниковые снимки (Яндекс/Google) и OpenStreetMap — контур корпуса, пролёты по фонарям кровли; высоты в OSM ненадёжны;
- пресс-релизы и каталоги SMS group, Danieli, Siemens по поставленным линиям;
- корпоративные журналы ТМК, metalinfo.ru, «Коммерсантъ», фото/видеоэкскурсии;
- ГОСТ/ТУ на продукцию — параметры для модели процесса;
- zakupki.gov.ru (223-ФЗ): ТЗ на реконструкцию иногда содержат планировки — искать по заказчику вручную.

Через завод (под NDA), запросить:
1. Генплан и архитектурно-строительные планы корпуса (оси, пролёты, отметки, краны); BIM в IFC, если есть.
2. Планировку (технологическую компоновку) оборудования.
3. Технологическую схему потока и регламент.
4. Перечень оборудования с паспортами (габариты, производительность).
5. Облако точек лазерного сканирования (точность до сантиметров).
6. Выгрузки из MES/АСУ ТП для живой симуляции.

## План работ
1. Демо по открытым данным: «Высота 239» (контур со спутника, состав линии SMS, фото участков) в технологии `plant-twin`.
2. Пилот с заводом: NDA → пакет документов → точная модель одного цеха → подключение к данным.
3. Масштабирование на другие цеха того же завода.
